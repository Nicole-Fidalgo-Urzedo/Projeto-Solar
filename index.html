Metodologia

Como os Dados são Processados

Fluxo de trabalho completo desde a aquisição até a análise final

1

Aquisição de Dados

Download de imagens do Google Open Buildings 2.5D Temporal e Copernicus DEM GLO-30 via Google Earth Engine.

2

Extração de Footprints

Utilização do Google Open Buildings V3 para obter os polígonos de cada edifício detectado na área de estudo.

3

Cálculo de Altura

A altura é obtida diretamente do dataset Google Open Buildings 2.5D, que utiliza machine learning para estimar alturas a partir de imagens Sentinel-2.

Altura = building_height (Google ML)
4

Estimativa de Andares

O número de pavimentos é estimado dividindo a altura total pela altura média de um andar (3 metros).

Nº Andares = ARREDONDAR(Altura ÷ 3.0)
5

Cálculo de Cotas

A elevação da base vem do DEM e a cota do topo é calculada somando a altura do edifício.

Cota Base = DEM (elevação do terreno)
Cota Topo = Cota Base + Altura
6

Classificação

Os edifícios são classificados por porte conforme o número de pavimentos.

Baixo: 1-2 pav | Médio: 3-5 pav | Alto: 6-10 pav | Muito Alto: >10 pav
